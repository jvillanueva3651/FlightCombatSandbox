# Godot 4 (.NET) with C#

We build on Godot 4's .NET edition and write C#. The team is one beginner plus an AI pair programmer, so the deciding factor was how much of the project is plain text: Godot stores scenes and settings as text, so code and scenes alike can be built, reviewed and tested from the command line, while Unity wires much of a project through its editor UI and Unreal's Blueprints are binary. C# over GDScript for compile-time type checking as the codebase grows. Accepted gaps: no built-in terrain and a smaller asset ecosystem than Unity.
