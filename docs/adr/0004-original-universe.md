# Original universe, no borrowed IP

The game copies Ace Combat's rules, not its world: nations, aircraft, superweapons, characters and music are all original, because Ace Combat's names and designs belong to Bandai Namco and real aircraft names are their manufacturers' trademarks. Staying original keeps a public release possible. No lore is written yet; the sandbox comes first.

One exception, for personal use only: the developer may keep real Ace Combat and Project Wingman music in a private Pack for their own testing. That Pack lives outside the repository and is never included in a build or release.
